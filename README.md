# YADRO-schemotech-2025-2026-project
# Автоматическое исследование фильтров (АЧХ и ФЧХ)

Проект измеряет АЧХ и ФЧХ различных фильтров (ФНЧ, ФВЧ, полосовой, мост Вина) с помощью генератора и осциллографа.

## Кто что делает

`server.py`

Python-сервер (gRPC) для работы с приборами.

Что делает:
- подключает генератор и осциллограф через `pyvisa`
- принимает gRPC-команды от Go
- отправляет SCPI-команды в железо
- читает ответы приборов (Vin, Vout, Phase)
- отдаёт данные в Go
- если приборов нет — работает в Mock-режиме (симуляция)

`main.go`

Основная логика измерения.

Что делает:
- читает `.yaml` конфиг эксперимента
- подключается к `server.py` по gRPC
- настраивает генератор
- делает sweep по частоте
- измеряет параметры на каждой точке
- рассчитывает идеальную теорию по формулам
- строит и сохраняет графики АЧХ и ФЧХ (используя `gonum/plot`)

`configs/*.yaml`

Конфиги экспериментов (`lpf_rc.yaml`, `wien_bridge.yaml` и т.д.).

Что хранят:
- тип фильтра (`mode`)
- номиналы R и C
- диапазон частот и число точек
- параметры сигнала (амплитуда, форма)
- пути сохранения графиков

## Как запускать

### 1. Установить зависимости Python

```bash
pip install pyvisa grpcio grpcio-tools
```

### 2. Установить зависимости Go

```bash
go mod tidy
```

### 3. Запустить Python-сервер

```bash
python internal/python_server/server.py
```

### 4. Запустить измерение

В новом терминале запускаем Go-клиент с нужным конфигом (например, для ФНЧ):

```bash
go run cmd/main.go -cfg configs/lpf_rc.yaml
```

После этого появятся файлы:
```text
output/lpf_gain.png
output/lpf_phase.png
```

## Порядок работы

1. `server.py` поднимает gRPC-сервис для работы с приборами.
2. `main.go` читает параметры из выбранного `yaml`.
3. `main.go` управляет генератором и осциллографом через gRPC.
4. `main.go` рассчитывает математику и сохраняет готовые графики в `output/`.
